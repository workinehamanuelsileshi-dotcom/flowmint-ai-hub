# Reposition Flowmint as an AI Automation + Website Agency

## Goal
Preserve the current Flowmint design system, page composition, motion, cards, imagery, and marketplace DNA while changing the homepage message from a live automation marketplace to a premium agency that builds websites, automation, and connected digital systems.

## Homepage changes

1. **Hero and navigation**
   - Keep the existing animated word-globe hero and scroll-reactive glass navigation.
   - Replace the hero headline, supporting copy, CTAs, and supporting line with the requested agency messaging.
   - Update the globe wording to reflect websites, automation, and systems without changing the component or animation.
   - Rename navigation items to Services, How It Works, Work, About, and a subtle “Marketplace — Coming Soon”; make “Start a Project” the primary action.

2. **Recontextualize existing sections**
   - Keep the ecosystem logo strip and describe the tools Flowmint connects.
   - Reuse the current problem cards for fragmented website, inquiry, and manual-work problems.
   - Turn the existing Solution section into “Digital systems built around your business,” retaining the workflow UI and changing its nodes to Social Media → Website → AI Assistant → Lead Capture → Follow-up → Customer.
   - Reuse the full-width marketplace browser mockup as a systems/work showcase rather than removing it.
   - Reframe Business DNA as a discovery/system blueprint section using the current process visualization.

3. **Services, process, and example work**
   - Reuse category pills and image cards for Website Development, AI Automation, and Digital Systems, including the requested website types.
   - Keep the four-step process cards and change them to Discover, Design, Build, Launch.
   - Reuse featured automation cards as clearly labeled “Concept” or “Example System” projects, with no invented clients, ratings, prices, ROI, or performance claims.
   - Rework the bento grid into concrete agency capabilities while retaining all micro-visuals, hover behavior, and card styling.

4. **Social-to-customer journey and future marketplace**
   - Use the existing workflow/card components to explain how social attention becomes website visits, qualified leads, follow-up, and customers.
   - Preserve the existing creator/marketplace visual section as a smaller future-facing “The marketplace is coming” section with a waitlist CTA.
   - Keep the `/creators` and `/creators/apply` routes intact so marketplace functionality remains recoverable.

5. **Trust, FAQ, CTA, and lead form**
   - Remove or rewrite all unsupported marketplace statistics, ratings, creator profiles, payout totals, ROI claims, and customer outcome numbers.
   - Update FAQ copy for agency services, timelines, ownership, and engagement.
   - Keep the existing CTA backgrounds and treatments, changing the copy to “Let’s build your system.”
   - Reuse the current form visual language for an in-page project form with Name, Business, Website, Social Media, Business Type, and service need options. Submission remains a transparent preview interaction unless a backend is requested.
   - Update footer language and links for the agency, retaining the oversized Flowmint wordmark and a subtle Marketplace Coming Soon link.

## Technical details
- Limit changes primarily to the homepage route and the existing Hero 09 content; preserve shared styles and components.
- Add semantic section IDs so the revised navigation and CTAs scroll to real destinations.
- Keep responsive behavior and animations, while replacing only content/data and any misleading marketplace metadata.
- Update homepage title, description, Open Graph, and Twitter metadata for the new positioning.
- Validate the page at desktop and mobile sizes, including hero readability, workflow labels, form states, anchors, and console/build health.
